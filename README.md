# Hirosaki Game\n\nBot Discord de jeu et d'économie avec commandes préfixées par +.\n\n## Fonctionnalités\n\n- Argent gagné en participant au serveur, avec cooldown anti-spam\n- Travail, récompense quotidienne, banque et classement\n- Vol avec risque, cooldown et protection contre les abus\n- Jeux : blackjack, pile ou face, dés, machine à sous et roulette\n- Commandes d'administration pour gérer l'économie\n- Sauvegarde locale dans data/economy.json\n\n## Installation\n\n1. Installer Node.js 18.17 ou plus récent.\n2. Installer les dépendances avec : npm install\n3. Copier .env.example vers .env et renseigner DISCORD_TOKEN.\n4. Dans le portail développeur Discord, activer Message Content Intent.\n5. Démarrer le bot avec : npm start\n\n## Commandes joueurs\n\n+help — afficher toutes les commandes\n+balance — voir le portefeuille et la banque\n+work — travailler avec un cooldown\n+daily — récupérer la récompense quotidienne\n+deposit <montant|all> — déposer à la banque\n+withdraw <montant|all> — retirer de la banque\n+leaderboard — classement des fortunes\n+steal @membre — tenter de voler le portefeuille d'un membre\n+blackjack <mise>, puis +hit ou +stand\n+coinflip <mise> <pile|face>\n+dice <mise> <1-6>\n+slots <mise>\n+roulette <mise> <rouge|noir|0-36>\n\n## Commandes administrateur\n\n+addmoney @membre <montant>\n\nLa permission Administrateur est nécessaire pour +addmoney.\n\n## Déploiement Railway\n\nDéfinir DISCORD_TOKEN dans les variables d'environnement du service et utiliser npm start comme commande de démarrage.\nLe stockage local peut être perdu lors d'un redeploy. Pour une économie durable, utiliser un volume Railway ou migrer la sauvegarde vers PostgreSQL.\n\nNe commite jamais le vrai token Discord.\n
